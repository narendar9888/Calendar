# 📅 Smart Calendar App

A modern, responsive calendar application built with **React** that helps users organize their schedule, manage events, and stay productive. The application supports **Month, Week, and Day views**, event management, dark mode, and persistent local storage.

---

# ✨ Features

* 📅 Month View
* 📆 Week View
* 🗓 Day View
* ➕ Add Events
* ✏️ Edit Events
* 🗑 Delete Events
* 🔍 Search Events
* 📂 Event Categories
* 🎨 Color Picker
* 🌙 Dark Mode
* 💾 Local Storage
* 📱 Responsive Design
* ⚡ Fast Performance
* 🎯 Modern UI

### Event Management

* Create new events

* Delete events
* Event title
* Description
* Date
* Time
* Category
* Event color

### Search

Search events instantly by title.

### Categories

Organize events into categories such as:

* Study
* Work
* Meeting
* Personal
* Health
* Travel
* Birthday
